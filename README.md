# 虎牙粉丝徽章批量打卡

该油猴脚本以虎牙直播间 518518 作为入口，通过虎牙页面自带的 TTP/WUP 客户端获取徽章列表，并按主播 UID 直接打卡。脚本不会再为每枚徽章打开一个直播间。

脚本只调用三个虎牙服务：

- `liveui/queryBadgeInfoList`：读取账号拥有的普通徽章。
- `wupui/getFansSign`：判断指定主播今日是否已经打卡。
- `wupui/setFansSign`：为指定主播执行每日打卡。

不会领取或执行其他任务。

## 安装

1. 浏览器安装并启用 Tampermonkey（油猴）。
2. 打开 Tampermonkey 管理面板，选择“添加新脚本”。
3. 删除编辑器里的示例内容。
4. 将 `huya-badge-checkin.user.js` 的全部内容粘贴进去并保存。
5. 确认 Tampermonkey 对 `www.huya.com` 有运行权限。

## 使用

1. 保持虎牙账号已登录。
2. 打开入口直播间：<https://www.huya.com/518518>
3. 点击页面左下方脚本面板中的“读取徽章并开始打卡”。
4. 脚本会读取每枚徽章的主播 UID 和房间号，在当前页面依次打卡。
5. 如果出现验证码、登录失效或频率限制，任务会暂停。处理后点击“继续”。
6. 面板右上角的 `−` 可最小化，`×` 可将其隐藏到本次页面刷新为止；两者都不会中断正在进行的打卡。

## UID 与房间号

`queryBadgeInfoList` 返回的每个 `BadgeInfo` 同时包含：

```text
BadgeInfo.lUid                  徽章所属用户 UID，不用于打卡
BadgeInfo.tChannelInfo.lUid     主播 UID，打卡时使用
BadgeInfo.tChannelInfo.iRoomId  直播间房间号，仅用于展示或进入房间
```

顶层的 `BadgeInfo.lUid` 会在同一账号的所有徽章中重复；若误用它，列表会被错误去重成一条，并把打卡请求发给非主播 UID。

例如 518518 直播间当前对应的主播 UID 是 1430972471。打卡请求必须发送：

```text
FansSignReq.lPid = 1430972471
```

不能发送：

```text
FansSignReq.lPid = 518518
```

## 处理规则

- 以主播 UID 去重，不以房间号去重。
- 每次打卡前先调用 `getFansSign`，已完成则直接跳过。
- `setFansSign` 返回 `iCode === 0` 才视为接口调用成功。
- 成功后再次调用 `getFansSign` 验证签到位。
- 普通失败最多重试一次；登录、验证码或风控错误会暂停整个任务。
- 每枚徽章之间随机等待约 1.6～2.8 秒。
- “暂停”会停止发送后续请求；“清除记录”会在当前请求结束后停止。

## 注意

- 脚本通过 `unsafeWindow.TTP` 复用虎牙页面自己的 TAF/WUP 编码和登录状态，不会导出 Cookie。
- 这些属于虎牙内部页面接口，并非公开 API；虎牙改版后，请求结构或对象名称可能变化。
- 自动化操作可能受到平台频率限制或账号风控，请控制使用频率，并自行确认符合虎牙当前规则。
